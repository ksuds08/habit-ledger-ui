# Habit Ledger

A calm, daily habit and focus streak ledger built with React, TypeScript, Tailwind CSS v4, Lucide icons, and Vercel UI SDK (`@ui-sdk/react`).

## Features

- Four starter habits with realistic 7-day history
- Interactive 7-day completion toggles with automatic streak calculation
- Weekly completion summary strip with progress indicator and daily totals
- Add Habit dialog with category and weekly target selectors
- Local browser persistence via `localStorage`
